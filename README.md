# Smart Expense Tracker

A simple desktop expense tracking application built using **Java Swing**.

## Features
* **Graphical User Interface (GUI):** Easy-to-use window to input categories and amounts.
* **Permanent Local Storage:** Automatically saves and loads your expense history using a local text file.

## How to Run
1. Download the `ExpenseTrackerApp.java` file.
2. Compile and run it using your favorite Java IDE or terminal.
